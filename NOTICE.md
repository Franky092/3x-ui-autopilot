# Лицензии

Код 3X-UI Autopilot (каталог `autopilot/`, `index.html`, `install.sh`, `tools/`, `tests/`) распространяется под лицензией MIT, см. [LICENSE](LICENSE).

Autopilot **не включает** перечисленные ниже программы в свой код: он скачивает или устанавливает их отдельно и запускает как самостоятельные программы. У каждой своя лицензия; ниже указаны данные, которые показывает репозиторий проекта на момент сборки релиза, и откуда программа берётся.

| Программа | Лицензия | Что делает и откуда берётся |
|---|---|---|
| 3X-UI (панель) | GPL-3.0 | Панель управления; закреплённая версия скачивается с GitHub Releases, SHA-256 проверяется |
| Xray-core | MPL-2.0 | Ядро VPN; поставляется внутри архива панели |
| nginx | BSD-2-Clause | Свой экземпляр на 443; пакет операционной системы |
| unbound | BSD-3-Clause | Собственный DNS; пакет операционной системы |
| fail2ban | GPL-2.0-or-later (см. файл COPYING проекта) | Защита SSH; пакет операционной системы |
| acme.sh | GPL-3.0 | Выпуск сертификата Let's Encrypt; скачивается закреплённой версией, SHA-256 проверяется |
| mita (Mieru) | GPL-3.0 | Служба Mieru; пакет `.deb` с GitHub Releases, SHA-256 проверяется. Ставится только по команде `autopilot mieru enable` |
| Nikki | GPL-3.0 | Клиент для роутера OpenWrt; ставит скрипт на самом роутере, только по команде `autopilot router` |
| OpenClash | MIT (по данным GitHub) | То же |
| PassWall 2 | GPL-3.0 | То же |

Условия лицензий этих программ действуют независимо от лицензии Autopilot. Страница `index.html` содержит только ссылки на сайты приложений-клиентов и не включает их код.
