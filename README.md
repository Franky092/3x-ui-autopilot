# 3X-UI Autopilot

3X-UI Autopilot устанавливает VPN-сервер с панелью 3X-UI и помогает управлять пользователями, подключениями и резервными копиями. Он рассчитан на владельца чистого VPS, который хочет настроить сервер одной командой и выдавать пользователям единую ссылку подписки. Сервер поддерживает 11 видов подключений; панель доступна через SSH-туннель. Для роутеров OpenWrt предусмотрена выдача команд автоустановки Nikki, OpenClash и PassWall 2.

## Быстрый старт

Нужен чистый VPS с Ubuntu 22.04/24.04 или Debian 12/13, архитектура amd64 или arm64, доступ root и публичный IPv4 непосредственно на сервере. Порты 80 и 443/TCP должны быть свободны и доступны снаружи. При настройке UFW Autopilot также открывает необходимые протокольные UDP-порты и SSH-порт.

Установка одной командой от root. Сначала скачайте скрипт и сверьте его контрольную сумму с указанной в описании релиза на GitHub (страница релиза и сам файл лежат в разных местах, поэтому подмена одного из них будет заметна):

```bash
curl -fsSLo install.sh https://raw.githubusercontent.com/Franky092/3x-ui-autopilot/v0.4.1/install.sh
echo "ac84faee9f13392ba20f05a2b8eab6e4da56069f5330ca94a044758564db52d3  install.sh" | sha256sum -c - && sh install.sh
```

`install.sh` скачивает архив релиза, сверяет его SHA-256 (она записана внутри скрипта) и запускает установщик. Параметры добавляются в конец: `sh install.sh --host 203.0.113.10 --sni www.microsoft.com` (`--xhttp-sni`, `--mtproto-sni` и `--no-ufw` тоже есть). Установщик покажет команду SSH-туннеля, локальный адрес панели и ссылку подписки. Учётные данные сохраняются в `/root/autopilot.txt` с правами только для root. Восстановление из копии: `sh install.sh restore /путь/к/копии.tar.gz`.

Чтобы подключиться, добавьте основную ссылку подписки в совместимое VPN-приложение. Команда `autopilot user link ИМЯ` повторно покажет её и QR-код. Страница [«Подключение»](index.html) работает локально в браузере: в неё можно вставить ссылку, выбрать устройство и посмотреть шаги.

## Подключения

| Протокол | Порт | Для чего |
|---|---:|---|
| REALITY | 443/TCP, SNI | VLESS с REALITY; маршрутизируется через nginx |
| XHTTP | 443/TCP, SNI | VLESS XHTTP; маршрутизируется через nginx |
| MTProto | 443/TCP, SNI | Прокси для Telegram; маршрутизируется через nginx |
| VLESS-WS | 443/TCP, SNI | VLESS через WebSocket за nginx |
| VMess-WS | 443/TCP, SNI | VMess через WebSocket за nginx |
| Trojan-gRPC | 443/TCP, SNI | Trojan через gRPC за nginx |
| Shadowsocks 2022 | 8388/TCP и UDP | Shadowsocks 2022 |
| Hysteria2 | 443/UDP | VPN-подключение на QUIC |
| TUIC | 8444/UDP | VPN-подключение на QUIC |
| AmneziaWG | 51821/UDP | Подключение AmneziaWG |
| AmneziaWG 3.1 | 51822/UDP | Подключение AmneziaWG версии 3.1 |

TCP-подключения на 443 выбираются по SNI. 80/TCP используется для выпуска и продления сертификата Let's Encrypt.

Если UFW включён, установщик разрешает SSH-порт, 80/TCP, 443/TCP и 443/UDP, 8388/TCP+UDP, 8444/UDP, 51821/UDP и 51822/UDP. С `--no-ufw` правила не меняются.

## Основные команды

| Команда | Назначение |
|---|---|
| `autopilot` | Открыть меню со стрелочной навигацией; язык выбирается через `--lang ru` или `--lang en` |
| `autopilot lang ru` / `autopilot lang en` | Сохранить язык меню |
| `autopilot user add ИМЯ --gb 100 --days 30 --devices 2` | Создать пользователя с лимитами; каждый флаг лимита можно опустить |
| `autopilot user list` | Список пользователей, трафик, срок и состояние |
| `autopilot user link ИМЯ` | Ссылки и QR-код пользователя |
| `autopilot user off ИМЯ` / `autopilot user on ИМЯ` | Отключить или включить пользователя |
| `autopilot user del ИМЯ` | Удалить пользователя |
| `autopilot status` / `autopilot stats` | Состояние сервера и статистика трафика |
| `autopilot check` / `autopilot check --fix` | Глубокая проверка (службы, порты, nginx, сертификат, DNS, подписка, ufw, диск); `--fix` безопасно чинит найденное |
| `autopilot net` | Показать подключения, порты и сайты-прикрытия |
| `autopilot net site reality\|xhttp\|mtproto САЙТ` | Сменить сайт-прикрытие (сайт должен поддерживать TLS 1.3 и HTTP/2, у каждого подключения свой) |
| `autopilot net port ИМЯ ПОРТ` | Сменить публичный порт Shadowsocks, Hysteria2, TUIC или AmneziaWG (правила ufw меняются сами) |
| `autopilot update [--check]` | Обновить панель до закреплённой версии: с копией до начала и откатом, если панель не поднялась |
| `autopilot notify setup` | Настроить необязательные уведомления Telegram |
| `autopilot cert status` / `renew` / `reload` | Проверить сертификат, запросить заново или перечитать его службами. Продлением занимается таймер (`cert auto` раз в 12 часов: выпускает новый, когда осталось меньше 3 суток) |
| `autopilot harden ssh` | Выключить вход по паролю SSH после проверки ключа; есть `--undo` |
| `autopilot backup` | Создать резервную копию; `--encrypt` запросит пароль |
| `autopilot backup auto on` / `off` / `key` | Настроить ежедневные зашифрованные копии и показать ключ |
| `autopilot restore ФАЙЛ` | Восстановить сервер из копии на чистом поддерживаемом VPS |
| `autopilot uninstall` | Удалить Autopilot после подтверждения |
| `autopilot router [nikki\|openclash\|passwall2] --user ИМЯ` | Выдать команду автоустановки клиента на OpenWrt |
| `autopilot mieru enable` / `disable` / `status` | Включить отдельную службу Mieru (mita) для ваших пользователей; свои порты и пользователей mita не трогает |

## Роутер OpenWrt

Команда `autopilot router` покажет готовую строку для выполнения по SSH на роутере. Автоустановка поддерживает Nikki, OpenClash и PassWall 2; для первых двух используется Clash-подписка, для PassWall 2 — основная. Скрипт устанавливает приложение и прописывает или загружает подписку, но сам VPN не запускает: это нужно включить в LuCI. Автоустановка PassWall 2 поддерживается на OpenWrt с менеджером пакетов apk; при opkg скрипт сообщает о необходимости ручной установки.

## Резервные копии, восстановление и удаление

Обычная копия хранится в `/var/backups/autopilot` и не зашифрована. Для копии с паролем используйте `autopilot backup --encrypt`. Автокопии зашифрованы, создаются ежедневно примерно в 04:30; ключ покажет `autopilot backup auto key`. Сохраните ключ отдельно от файлов копий.

Для восстановления скопируйте файл на чистый поддерживаемый сервер и выполните `autopilot restore /путь/к/копии.tar.gz` (для `.enc` будет запрошен пароль). Восстановление повторно устанавливает сервер, меняет старый IP на новый в соответствующих подключениях и выпускает сертификат заново.

`autopilot uninstall` показывает, что будет удалено, и после подтверждения сначала делает копию в `/root` (если не указан `--no-backup`), затем удаляет службы и файлы Autopilot; `--dry-run` только показывает план. Ограничение входа по паролю в SSH (`harden ssh`) и архивы в `/var/backups/autopilot` остаются; установленные системные пакеты не удаляются. Перед удалением сохраните отдельно ключ автокопий (`autopilot backup auto key`): он находится в удаляемой конфигурации и нужен для расшифровки этих архивов.

## Безопасность

Панель слушает только loopback и доступна через SSH-туннель; ссылки подписки, ключи и резервные копии — секреты. Подробности о хранении данных, ограничениях и сообщении об уязвимостях — в [SECURITY.md](SECURITY.md) и [PRIVACY.md](PRIVACY.md).

## Собственный DNS и Mieru

При установке поднимается рекурсивный DNS (unbound) без внешних серверов-пересылщиков: им пользуются клиенты AmneziaWG. Он слушает `127.0.0.1:5353` и публичный адрес сервера на 53, принимает запросы только от самого сервера, а порт 53 в UFW закрыт. DNS самого сервера не меняется.

Mieru — отдельная служба `mita`, а не подключение панели. `autopilot mieru enable` ставит её (если не стоит), заводит пользователей и добавляет ссылку `mierus://` в `autopilot user link`.
