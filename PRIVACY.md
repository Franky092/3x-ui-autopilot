# Приватность

## Внешние обращения

Сетевые обращения происходят для установки, выпуска сертификата и функций, которые вы включаете:

| Когда | Куда | Для чего |
|---|---|---|
| Установка и обновление списка пакетов ОС | Настроенные зеркала APT Ubuntu/Debian | Установка системных зависимостей |
| Установка панели | GitHub, релиз 3X-UI | Загрузка закреплённой версии панели |
| Выпуск/продление сертификата | GitHub (`raw.githubusercontent.com`) и Let's Encrypt | Загрузка зафиксированной версии acme.sh и запрос сертификата на IPv4 сервера |
| Автоматический выбор сайтов-прикрытий | Выбранные сайты по HTTPS на 443/TCP | Проверка поддержки TLS 1.3 и HTTP/2; если имя задано флагом, проверяется указанный сайт |
| Работа собственного DNS | Корневые, TLD и авторитетные DNS-серверы | Рекурсивное разрешение имён для клиентов AmneziaWG без внешнего пересылщика; эти серверы видят нужные им запросы |
| Включение Mieru, только если вы запустили `autopilot mieru enable` | GitHub (релиз mita) | Загрузка пакета `mita` с проверкой SHA-256 |
| Уведомления, только если вы настроили Telegram | `api.telegram.org` | Отправка сообщений боту и в заданный чат |
| Автоустановка клиента на OpenWrt | GitHub; для PassWall 2 также SourceForge | Получение скриптов, релизных файлов и пакетов роутера; сам роутер выполняет эти загрузки |

При использовании обычных VPN-подключений сетевой трафик проходит через ваш VPS к выбранным адресатам. Autopilot не передаёт владельцу репозитория данные пользователей или статистику сервера.

## Что хранится на сервере

В базе панели хранятся пользователи, параметры подключений, ключи, лимиты и учёт трафика. В `/etc/autopilot/install.json` находятся параметры установки и API-токен панели; `/root/autopilot.txt` содержит данные входа панели, ссылку подписки и отдельные подключения первого пользователя. Приватный ключ сертификата хранится в `/etc/autopilot/certs/ip/privkey.pem`.

Токен Telegram и ID чата сохраняются в `/etc/autopilot/notify.env`, только если вы включили уведомления. Резервные копии по умолчанию не зашифрованы и включают базу панели, состояние установки и сертификаты; `notify.env` и ключ автокопий в них не попадают. Автоматические копии шифруются ключом из `/etc/autopilot/backup.key`.

Страница `index.html` обрабатывает вставленную ссылку в браузере и не отправляет её со страницы на внешний сайт. Не публикуйте ссылку подписки: она даёт доступ к серверу.

## Границы приватности VPN

VPN меняет маршрут сетевого трафика, но не скрывает все сведения о соединениях. Хостер VPS может видеть адреса соединений к серверу и исходящие сетевые назначения; интернет-провайдер клиента видит соединение с VPS и его метаданные. Сайты и другие адресаты видят выходящий адрес VPS и могут собирать данные на своей стороне. Соблюдайте HTTPS и правила приватности используемых приложений и сайтов.

В программе нет телеметрии. Сетевые обращения, связанные с настройкой сервера, перечислены выше; Telegram-обращения выполняются только после включения уведомлений.
