# Безопасность

## Сообщить об уязвимости

Если вы обнаружили уязвимость, откройте раздел **Security** на странице репозитория на GitHub и используйте доступный там способ конфиденциального сообщения. Не публикуйте рабочие ссылки подписки, пароли, токены, ключи или содержимое резервных копий в открытом issue.

## Секреты и их хранение

Секретами считаются токен API панели, пароль панели, ключи VPN, ссылки подписки, `backup.key`, данные `notify.env` и сами резервные копии.

| Данные | Где находятся | Доступ |
|---|---|---|
| Логин, пароль панели, ссылка подписки и подключения первого пользователя | `/root/autopilot.txt` | Файл доступен только root (`0600`) |
| API-токен панели и параметры установки | `/etc/autopilot/install.json` | Файл `0600`; каталог `/etc/x-ui` с базой панели имеет права `0700`, база — `0600` |
| VPN-ключи и параметры пользователей | База `/etc/x-ui/x-ui.db` | Каталог `/etc/x-ui` имеет права `0700`; при восстановлении база получает `0600` |
| Приватный ключ сертификата | `/etc/autopilot/certs/ip/privkey.pem` | `0600` |
| Токен бота и ID чата | `/etc/autopilot/notify.env` | `0600`; файл удаляется командой `autopilot notify off` |
| Ключ автоматических резервных копий | `/etc/autopilot/backup.key` | `0600`; в архивы резервных копий не включается |
| Пароли пользователей Mieru (если включён) | `/etc/autopilot/mieru.json` | `0600`; входит в резервные копии |
| Резервные копии | `/var/backups/autopilot` | Файлы `0600`, каталог `0700`; обычная копия не зашифрована |

Команда `x-ui setting` принимает пароль панели только аргументом, поэтому на доли секунды при установке пароль виден в списке процессов сервера. Используйте выделенный VPS и не запускайте установку в окружении с недоверенными локальными пользователями.

## Что делает Autopilot

- Панель 3X-UI слушает только `127.0.0.1`; для доступа используется SSH-туннель.
- Autopilot не выполняет сетевое автообновление своего Python-пакета или компонентов. Сертификат продлевается отдельно systemd-таймером.
- Программа не отправляет телеметрию.
- Собственный DNS (unbound) принимает запросы только от самого сервера и от localhost; порт 53 в UFW не открывается.
- Установка без `--no-ufw` включает UFW и разрешает SSH, 80/TCP, 443/TCP и UDP-порты подключений.
- fail2ban устанавливается и настраивает защиту SSH. Вход по SSH-паролю автоматически не отключается. Для перехода на ключевой вход есть `autopilot harden ssh`; команда проверяет наличие ключа и поддерживает откат через `autopilot harden ssh --undo`.

## Известные ограничения

- Если Let's Encrypt не выдаёт сертификат, установка продолжается с самоподписанным сертификатом. Для Hysteria2 и TUIC клиенту потребуется разрешить такое соединение; после открытия входящего 80/TCP можно повторить выпуск командой `autopilot cert renew`.
- Копии, созданные без `--encrypt`, содержат базу панели, ключи и состояние установки в открытом виде. Храните их как секреты.
- При ручном включении ограничения SSH сначала убедитесь, что вход по ключу работает в отдельной сессии; не закрывайте текущую сессию до проверки.
